MSR Water Reminder

MSR Water Reminder is a Windows desktop application designed to remind users to drink water while running quietly in the background.

Features

  • Runs in the Windows background
  • Automatically registers for Windows startup
  • Configurable reminder interval
  • Fullscreen drinking-water reminder
  • Live webcam preview
  • Face detection using OpenCV
  • Water-bottle detection using YOLO
  • Automatic local photo capture
  • Camera is released after the reminder closes

Install

python -m pip install -r requirements.txt
python water_reminder.py
