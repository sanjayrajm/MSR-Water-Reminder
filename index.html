MSR Water Reminder

A Windows desktop application designed to remind users to drink water while running quietly in the background.

Features

  • Runs in the Windows background
  • Automatically registers for Windows startup
  • Configurable reminder interval
  • Fullscreen drinking-water reminder
  • Live webcam preview
  • Face detection using OpenCV
  • Water-bottle detection using YOLO
  • Automatic local photo capture
  • Camera released after the reminder closes

Installation

python -m pip install -r requirements.txt
python water_reminder.py
